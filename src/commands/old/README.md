# Old Command Files (Archived)

These command files have been replaced with category-based parent commands.

## Replaced By

- **action.js** - Contains all action commands:
  - hug, kiss, slap, bite, nuzzle, pet, lick, tickle, poke, pinch, boop, handhold, highfive, greet, cheer

- **react.js** - Contains all reaction commands:
  - blush, pout, cry, laugh, smirk, wink, stare, dance

- **nsfw.js** - Contains all NSFW commands:
  - rape, suck, spank, edge, horny

## How It Works Now

Commands are now structured as:
- `/action [subcommand]` (e.g., `/action hug @user`)
- `/react [subcommand]` (e.g., `/react blush`)
- `/nsfw [subcommand]` (e.g., `/nsfw rape @user`)

This reduces command clutter and organizes commands more logically.
